# Retrieval-Augmented Generation (RAG) and Vector Embeddings

## What is RAG?
Retrieval-Augmented Generation (RAG) is an AI architecture that enhances the capabilities of Large Language Models (LLMs) by retrieving relevant contextual evidence from external knowledge stores before generating a response. This minimizes factual hallucinations and keeps model responses grounded in authoritative data.

## Vector Embeddings and Dense Retrieval
Dense retrieval relies on dense vector representations generated by text embedding models, such as MiniLM, BGE, or text-embedding-3. Semantic similarity is computed using cosine distance or dot products between query vectors and pre-indexed chunk vectors:
$$\text{Cosine Similarity}(u, v) = \frac{u \cdot v}{\|u\|_2 \|v\|_2}$$

## Chunking Strategies and Overlap
Documents must be segmented into semantically coherent text chunks. Standard chunking techniques use sliding windows with 500-token chunks and 80-token overlap to preserve continuity across chunk boundaries.

## Knowledge Graph Augmentation (GraphRAG)
While vector search identifies localized semantic matches, GraphRAG augments dense retrieval with structured knowledge graphs. Entities and directional relationships extracted from documents provide multi-hop traversal and discover cross-document connections that simple vector similarity might overlook.
